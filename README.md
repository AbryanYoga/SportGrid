# SportGrid

A modern, universal multi-sport Android application built with Jetpack Compose & Material 3, fetching real-time data from API-Sports.

## Features
- **Universal Multi-Sport Coverage**: Football, Basketball, Volleyball, Baseball, and Hockey.
- **Dynamic Dashboard**: Hero live matches, sport filter chips, popular leagues, today's matches, and transfer previews.
- **Live Scores**: Real-time scores with auto-refresh mechanism.
- **Transfer Market**: Football player transfers, previous and target clubs, fees, and dates.
- **Adaptive Layout**: Smooth scrolling, fully responsive for both Portrait and Landscape.
- **Multi-language**: Indonesian & English support.
- **Dark & Light Mode**: Electric volt & deep charcoal modern sports design.

## Setup & API Key
This app uses [API-Sports](https://api-sports.io/).
1. Get an API key from API-Sports dashboard.
2. Open `local.properties` in the project root.
3. Add the key:
   ```properties
   API_SPORTS_KEY=your_actual_api_sports_key
   ```
4. Build and run the project in Android Studio.
